# 引言

你是不是也经常遇到下面的情况   

![HSTS报错](https://img.pldduck.com/20260906141619679.png)

当 Chrome 出现这个页面的时候
过去大多数人都以为这个网站访问不了了，只能等他修好(包括我自己)  
但有时候有些网站当时又特别急着要用(Edge还好可以高级选项直接进入)  

# 正文
但是今天，我偶然看到一条帖子下面的评论。  
说遇到这种情况有一种办法可以直接解决。  

## 方法
方法就是在这个时候 用键盘盲输一个 **thisisunsafe**  
这样 Chrome 就可以临时加载这个网页，忽略 Https 问题。

## 解释

基于安全考虑目前很多网站都已经部署 HTTPS 加密连接，但有时候网站服务器出现问题时可能会退回到 HTTP 明文连接。而谷歌浏览器采用的 HSTS 严格传输安全机制，会强制浏览器和服务器之间必须通过 HTTPS 加密连接。  

遇到 HSTS 导致的无法加载时，正常情况下对访问者来说应该直接关闭页面，因为这种情况要么是网站服务器出现问题，要么是用户到该网站之间的连接遭到劫持，因此继续尝试访问存在潜在的安全隐患。   

不过谷歌也在 Chrome 中预留小彩蛋，只需要通过键盘盲打 thisisunsafe 即可绕过 HSTS 继续加载，输入 thisisunsafe 时页面不会有任何提示，当完成输入时 Chrome 就会自动重新加载这个页面。   

正常情况这个功能应该是给程序员临时测试网站用的，但是有些时候普通用户也可以使用，相当于用户已经知道这个连接不安全但签了个免责协议，所以谷歌会重新允许用户进行加载。

# 结语

理论上这也算不上是一个彩蛋,算是跟开发者之间的一个小秘密，主要是为了方便开发人员测试。  
此外，实测 Edge 也可以，但是没必要(因为 Edge 可以直接在高级选项中选择继续服务 bushi)。
