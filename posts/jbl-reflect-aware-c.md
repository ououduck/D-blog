# 起因
Duck在拼夕夕上逛着，突然看到一个商品封面写着“曾经1000圆”的耳机
点进去看了一下发现是JBL REFLECT AWARE C
拼夕夕上是卖的60左右 我就上B站搜了一下这款耳机，发现评价不错，而且问一下AI发现音质比我现在正在用的T110好，于是果断打开小黄鱼 ......

# 捡漏
打开小黄鱼立马搜索，结果就看到了一个只卖25的9成新的
如果你自己去看，你就会知道这个25有多划算
因为它不像那些 卖30、卖29 甚至拼多多上卖 60 的那样，那些卖的耳机线会有破皮的问题
而我看到的这一款虽然只有 25，但它的成色甚至更新更好
而且要知道，这耳机在14年出来的时候，可是要卖上千元

# 自用评价
1. 音质确实比T110要好一点(这里又得表扬Apple Music了)
2. 降噪毕竟是14年的产品，只能说适合骑车的时候过滤风噪，不过有总比没有好
3. 可以使用JBL的软件，稍微还是高级一点
4. 运动的时候要好得多，不像T110会出现很严重的听诊器效应
