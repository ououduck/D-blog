# 起因  
Duck在拼夕夕上逛着，突然看到一个商品封面写着“曾经1000圆”的耳机  
点进去看了一下发现是JBL REFLECT AWARE C  
拼夕夕上是卖的60左右 我就上B站搜了一下这款耳机，发现评价不错，而且问一下AI发现音质比我  现在正在用的T110好  
打开小黄鱼立马搜索，结果就看到了一个只卖25的9成新的    
要知道，这耳机在14年出来的时候，可是要卖上千元

# 自用评价  
1. 音质确实比T110要好一点(这里又得表扬Apple Music了)  
2. 降噪毕竟是14年的产品，只能说适合骑车的时候过滤风噪，不过有总比没有好  
3. 可以使用JBL的软件，稍微还是高级一点  
4. 运动的时候要好得多，不像T110会出现很严重的听诊器效应  

# 重要槽点  
因为毕竟是10多年前的产品了，而且现在你买到的基本都是9新或者全新的  
导致线的外面那层皮特别脆，基本就是搓一下就会碎掉的那种，特别是那几个原本就在盒子里面弯着的地方  
所以我还特意买那种修数据线的胶布，把它粘一圈  
说实话，还是很麻烦，而且粘好之后，还是有点不舒服
