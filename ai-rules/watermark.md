# 水印工具（Watermark）— AI 修改规则

## 功能概述

本地图片文字水印：图片选择/预览、水印样式配置（文字/字号/位置/透明度）、实时预览、PNG/JPEG 导出。全部在浏览器本地处理，不上传。

## 关键文件

- `src/pages/Watermark.tsx`
- `src/pages/watermark/watermarkRenderer.ts`（绘制/定位/文件名）

## 修改规则（必须遵守）

1. **本地处理**：所有操作在浏览器本地完成（FileReader/ObjectURL），禁止引入上传逻辑。
2. **加载健壮性**：`loadImage` 必须有超时兜底（onload/onerror 都可能不触发）；卸载守卫与代际（generation）防护保持。
3. **导出**：JPEG 导出必须铺白底（透明 PNG 导出 JPEG 不得出现大黑底）；`toBlob` 返回 null 必须报「导出失败」而非静默；导出期间禁止移除图片（按钮 disabled + 代际校验）。
4. **Y 轴夹紧**：文字定位夹紧必须保证上界不低于下界（高度小于半字号时退化为居中半可见，禁止整体越界不可见）。
5. **无障碍**：预览 canvas 必须有 `role="img"` 与可读名称。
6. **代码复用**：canvasToBlob 若与 coverExport 重复实现，应统一（修改一侧时同步另一侧语义）。

## 常见陷阱

- 浏览器 canvas 面积上限差异（Safari 约 1677 万像素）：超上限导出要给明确错误；
- 预览 canvas 与导出 canvas 是两份绘制，样式配置同步保持一致。
